# Network and Signal Troubleshooting (PakSim)

## Common checks
1. Restart the handset.
2. Reseat the SIM; inspect for physical damage.
3. Set network mode to Automatic or preferred LTE/4G.
4. Test the SIM in another compatible device.
5. Note the customer area/city for coverage investigation.

## When to escalate
If basic steps fail and the customer still has No Service / No Signal on multiple devices, create a technical complaint with area details. Do not invent outage ETAs.
