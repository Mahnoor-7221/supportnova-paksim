# Number Portability Support Policy

## Scope
This approved PakSim policy covers number portability complaints handled by Number Portability.

## Standard handling

## Categories
MNP Request, MNP Rejection, Porting Delay, Porting Status

## Service level
Default target: 72 hours.

## Safety
Escalate security-sensitive or otherwise mandatory cases according to the rule matrix.
