# Number Portability Resolution SOP

## Purpose
This PakSim demo SOP defines handling of mobile number portability complaints.

## Checks
Capture the porting request reference, current status and relevant account information.

## Resolution
Use the approved portability rules for eligibility, pending requests and failed requests.

## Escalation
Repeated delays, unresolved rejection reasons or regulatory-sensitive cases must be routed to Number Portability and escalated when the rule requires it.

## Communication
Do not guarantee a completion time unless it is supported by an approved policy or status record.
