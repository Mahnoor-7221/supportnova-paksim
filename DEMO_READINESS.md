## Evidence included

- 20 bundled policy/SOP documents processed into the knowledge base.
- 5,000 synthetic telecom complaint cases.
- 120 unseen cases reserved for evaluation.
- 100 unseen cases already evaluated with the independent Python validation pipeline.
- Manual-review and escalation records generated by the deterministic validation/rule pipeline.
- Reviewer and manager demo roles/users.

## Prepare or refresh the demo database

From `backend/`:

```bash
PYTHONPATH=. python scripts/prepare_demo_evidence.py
```

If no live AI key is configured, the application automatically uses the deterministic offline baseline. The preparation script can be forced to offline mode with:

```bash
AI_PROVIDER=offline LOVABLE_API_KEY= GEMINI_API_KEY= PYTHONPATH=. python scripts/prepare_demo_evidence.py
```

## Backend tests

```bash
PYTHONPATH=. pytest -q
```

## Frontend

```bash
cd frontend
npm ci
npm run build
npm run dev
```

Do not commit `node_modules/` or real `.env` secrets.
